# Локальные ресурсы и внешние соединения

Интерфейс не загружает JavaScript, CSS, шрифты или изображения со сторонних CDN. Локальные файлы здесь означают файлы с того же адреса, что и сайт; общая база продолжает работать на сервере.

| Ресурс | Как загружается |
| --- | --- |
| Интерфейс и расчёты | Модули из `dist/` с адреса сайта |
| Чтение Excel | `xlsx-reader.js`, собранный вместе с приложением |
| Библиотека ЮKassa для старых встроенных платежей | Только `yookassa-sdk.js` с адреса сайта; исходный файл сохранён без изменений, происхождение и SHA-256 — в `yookassa-sdk-source.txt` |
| Стили и логотипы | Файлы из `dist/`; внешних шрифтов нет |
| ВКонтакте | Обычная ссылка, открывается по нажатию; сторонний SDK не подключён |

Резервная загрузка JavaScript с адресов платёжного провайдера удалена. Политика `script-src 'self'` действует на GitHub Pages, самостоятельном Node.js-сервере и облачном сервере. Контакты с платёжным сервисом разрешены для защищённых iframe и запросов самого платёжного сервиса, а не для загрузки стороннего JavaScript в интерфейс мастерской.

## Соединения, которые остаются необходимыми

- Кабинеты, расписание, запись, остатки и чеки используют API. На GitHub Pages его адрес задаётся опубликованным `config.js`; API сейчас размещён отдельно. Копирование JavaScript не переносит этот сервер или базу.
- Новые оплаты открывают защищённую страницу ЮKassa. Для старых встроенных оплат локальная библиотека открывает iframe платёжного провайдера. Платёжная страница, банк и проверка оплаты требуют сети; их нельзя заменить локальной копией или имитацией успешной оплаты.
- Если недоступен сам домен GitHub Pages, локальность файлов внутри сайта не меняет маршрут до хостинга.

Работу без VPN в конкретной российской сети нужно проверять с этой сети. Успешная проверка из другой страны её не подтверждает. Для устранения зависимости от отдельного облачного API предусмотрено размещение всего приложения на одном доступном домене собственного сервера: `YASNA_API_BASE=''` уже используется по умолчанию в варианте Node.js. Порядок переноса с сохранением данных — [availability-ru.md](availability-ru.md).

## Контроль при публикации

`npm run audit:assets` проверяет локальность ресурсов HTML/CSS, графа импортов JavaScript и ограничение CSP. Проверка выполняется в GitHub Actions перед тестами и публикацией. Автоматические тесты также проверяют, что сбой локальной библиотеки не вызывает загрузку JavaScript с внешних адресов, и что завершение оплаты подтверждается сервером.
