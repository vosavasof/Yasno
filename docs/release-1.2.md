# Семейная запись и общий сайт

## Изменения в коде

- В семейной оплате можно отметить всех или отдельных детей. Одна оплата для двух и более детей даёт скидку 10%. Пробный урок — 1 000 ₽, разовый — 1 600 ₽, абонемент 4 занятия — 5 500 ₽. Тарифы редактируются мастером; скидка и остаток аванса считаются сервером. Новые покупки семьи блокируются, пока предыдущая семейная оплата не проверена. Реальные начисления происходят только после проверки ЮKassa; тесты баланс не меняют.
- Форма `/api/public/enroll` создаёт ребёнка, семью и запись без ручного подтверждения. Для повторной отправки используется случайный ключ формы, поэтому повтор не занимает второе место. Контактный телефон не предоставляет доступ к существующей семье. Имеющий доступ родитель может записать второго ребёнка в свою семью. Проверка последнего места и запись выполняются атомарно. Старые заявки сохраняются в истории.
- После регистрации можно оплатить сейчас или позже; неоплаченная запись уже занимает место. Для отметки посещения с платным списанием сначала требуется внести оплату.
- Мастер выбирает участников новой группы списком. Журнал позволяет поставить отметку или открыть карточку участника с посещениями, оплатами, авансом и контактами.
- Форматы: групповые, индивидуальные, семейные мастер-классы, дни рождения, мастер-классы для компаний. Вместимость индивидуального занятия — 1. Запись на эти форматы использует существующую модель детской мастерской; отдельный корпоративный договор/массовый список взрослых не автоматизирован.
- Светлая/тёмная тема сохраняется в браузере. Скрипты и стили раздаются с сайта.
- Мастер задаёт HTTPS-ссылку на действующий документ о персональных данных. До её добавления автоматическая регистрация закрыта. При согласии сохраняются версия ссылки и время. Вымышленный юридический документ не подставляется.
- Файл чека можно прикрепить к оплате и скачать. Сервер проверяет право на скачивание. В магазине с включённой передачей чеков можно явно включить подключённый сервис ЮKassa. Для него отправляются данные покупателя и сумма; статус регистрации проверяется отдельной командой. Документ НПД формирует подключённый сервис, а не приложение. Если ЮKassa не сообщает статус, интерфейс не объявляет чек готовым. Сам факт успешной оплаты не заменяет чек НПД.
- Для iPhone подготовлены PWA, подписка Web Push и тест доставки с подтверждением показа от Service Worker. Доставка проверяется по действующей сессии; после отзыва доступа сообщения не отправляются. Устаревшие подписки удаляются. Принятие сообщения push-службой не считается подтверждением его показа.

## Проверено автоматически

Тарифы и скидка, защита чужой семьи, зачисление двум детям одним подтверждённым платежом без повторов, запрет повторного пробного урока, последняя свободная запись при параллельных запросах, повтор формы, форматы/вместимость, сохранение документа согласия, получение прикреплённого PDF, проверка ответа ЮKassa о чеке, push-статусы/подписки/отзыв сессии на моделируемой доставке, GitHub CORS и вход без сторонних cookies.

## Требуется до начала работы

1. Создать сервер и DNS/HTTPS в своём аккаунте Яндекс Cloud. Ресурсы в чужом аккаунте не создавались, оплата облака не активировалась.
2. Настроить GitHub `YASNA_SHARED_API_BASE`. Пока он пуст, доступна публичная страница с форматами и ценами, кабинеты/запись/оплата не работают.
3. Добавить настоящий документ о персональных данных.
4. Проверить магазин ЮKassa, webhook нового API, тестовую оплату, возврат и формирование документа в подключённом сервисе НПД. Автоматические тесты используют вымышленные данные и не создают настоящих чеков ФНС.
5. Проверить push на настоящем iPhone: HTTPS, iOS 16.4+, установка сайта на экран «Домой», запуск оттуда, согласие, тест уведомления. Фактическое получение на вашем телефоне пока не проверено; программная проверка не подменяет этот этап.
