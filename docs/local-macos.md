Ясна для macOS — локальная база

1. Скачайте Yasna-macOS.zip и распакуйте архив целиком.
2. Откройте папку Yasna и дважды нажмите «Запустить Ясну.command».
3. При первом запуске придумайте пароль мастера длиной от 12 символов и повторите его в Терминале. Ввод не отображается. Логин — master.
4. Браузер откроется автоматически на адресе http://127.0.0.1 с локальным портом. Войдите с созданным паролем.

Отдельно устанавливать Node.js, npm или Docker не требуется. Пакет содержит официальные среды Node.js для Mac с Apple Silicon и Intel и автоматически выбирает подходящую. Для первого скачивания нужен интернет; обычный локальный учёт после распаковки работает без интернета и VPN.

Если macOS запрашивает подтверждение открытия скачанного файла, откройте его контекстное меню → «Открыть» и подтвердите запуск, если доверяете скачанному пакету. Не отключайте системную защиту. Если система отказывается запускать файл, сохраните точный текст сообщения для диагностики.

Данные хранятся отдельно от программы:
~/Library/Application Support/Yasna/

Основной файл — yasna.sqlite; parent-links.key нужен для сохранения действующих локальных сессий/ссылок и расшифровки настроек. Папку данных не удаляйте. Обновление приложения заменяет папку с программой, но не папку данных.

Пока работаете, оставляйте окно Терминала открытым. Завершение: Control+C. Для следующего запуска снова откройте «Запустить Ясну.command». Логин и пароль останутся прежними.

Что работает локально

Расписание, запись, журнал посещений, дети и родители, абонементы, цена занятия, ручной учёт оплат и аванса, прикрепление чеков, CSV и резервные копии. Сайт и API находятся на одном локальном адресе; внешняя серверная часть не используется. Приложение слушает только 127.0.0.1 и не открывает порт для других компьютеров.

Оплаты

Принимайте деньги наличными или переводом и вносите оплату вручную. Онлайн-оплата и запросы к платёжному API в этом режиме отключены. Публичные кабинеты родителей и подтверждения платежей из интернета недоступны. Локальный родительский просмотр можно открыть на этом же компьютере.

Перенос ранее внесённых данных

Новая локальная база изначально пустая. Программа не скачивает прежнюю базу и не подставляет демонстрационные записи. В прежнем кабинете мастера скачайте резервную копию, затем в локальном приложении выберите «Настройки → Восстановить» и укажите этот JSON-файл. Для получения прежней копии может однократно понадобиться рабочее соединение с прежним сервером. Не присылайте пароли или ключи в переписке.

Восстановление заменяет текущие локальные записи: если уже начали работу, сначала сохраните копию. После переноса проверьте детей, остатки, оплаты и прикреплённые чеки. Прежние публичные ссылки родителей не превращаются в локальные автоматически.

Резервные копии

В интерфейсе скачивайте JSON-копию с данными и чеками. Для полной копии с паролем и внутренними настройками завершите приложение и сохраните всю папку ~/Library/Application Support/Yasna/ на отдельный носитель. При открытом приложении не копируйте один файл SQLite отдельно от WAL/SHM.

Технически: Node.js 24, SQLite, HTML/CSS/JavaScript. В рабочем пакете отсутствуют реальные данные и предустановленный общий пароль.
