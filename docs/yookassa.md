# ЮKassa и чеки НПД

## Включение

1. Откройте кабинет мастера → **Настройки → Подключение ЮKassa** (или **Оплаты → Настроить**).
2. В кабинете ЮKassa найдите Shop ID и секретный ключ. Введите их в форме на сайте. Не отправляйте ключ в переписку и не добавляйте его в GitHub.
3. Начните с тестового магазина и ключа `test_…`. Выберите тестовый режим, включите создание платежей и сохраните. Тестовые платежи видны отдельно, рабочие оплаты и остатки занятий они не меняют.
4. В ЮKassa → Интеграция → HTTP-уведомления добавьте адрес из формы на сайте для событий `payment.succeeded` и `payment.canceled`. Адрес ведёт на сервер приложения, GitHub Pages уведомления не обрабатывает.
5. Проверьте тестовую оплату. Для рабочего запуска укажите Shop ID рабочего магазина, ключ `live_…`, рабочий режим и включите создание платежей. Сначала завершите или дождитесь отмены незавершённых тестовых платежей.

Родитель открывает «Оплаты» или «Оплатить абонемент» в кабинете семьи, выбирает ребёнка и переходит на страницу ЮKassa. На сайте мастерской данные банковских карт не запрашиваются. Стоимость и число занятий берутся из настроек на сервере. После возврата статус проверяется автоматически; его также можно проверить кнопкой «Проверить оплату». Уведомление сервера зачисляет занятия, даже если родитель не вернулся на сайт.

Ключ зашифрован AES-GCM в отдельной серверной таблице, не возвращается в API и не попадает в клиентские файлы или экспорт клиентов. На размещённом сервере ключ шифрования выводится из существующего runtime-секрета `PARENT_LINK_SECRET`; на VPS — из `data/parent-links.key`. Храните этот ключ вместе с полной резервной копией базы. Смена ключа шифрования без переноса данных сделает настройки недоступными. JSON-экспорт рабочего журнала не содержит настроек ЮKassa и реестра заказов; для полного восстановления нужна вся база и ключ (на VPS `npm run backup`).

## Подтверждение оплаты

Сайт создаёт заказ до запроса к ЮKassa и повторяет неопределённый запрос с тем же `Idempotence-Key`. Повторное нажатие для того же ребёнка и абонемента возвращает незавершённый заказ. Уведомление от ЮKassa служит сигналом для серверного GET-запроса к API: проверяются ID заказа, магазин, сумма, валюта, тестовый режим, метаданные и статус `succeeded`/`paid`. Переход по ссылке возврата сам по себе не подтверждает оплату. Зачисление имеет постоянный ID и защищено от повторных уведомлений и одновременных изменений журнала.

При сетевой ошибке повторите открытие/проверку, не создавайте параллельную ручную оплату. Если попытка создания не определилась за 23 часа, мастер сверяет её в ЮKassa: новый заказ автоматически не создаётся, чтобы не допустить повторного списания. Выключение создания платежей сохраняет возможность подтвердить уже созданные заказы. Сменить магазин или режим при незавершённых заказах нельзя.

Возвраты денег и регулярные списания в эту интеграцию не включены. Возврат в кабинете ЮKassa требует отдельной сверки абонемента и чека НПД; автоматического уменьшения остатка по возврату сейчас нет.

## «Мой налог»: две разные задачи

**Регистрация дохода и чек.** По актуальной документации ЮKassa с 29 декабря 2025 года прекращена поддержка чеков самозанятых. Оплата через эквайринг сама по себе не регистрирует доход в «Мой налог», а платёжная квитанция не заменяет чек НПД. Сейчас мастер формирует чек в «Мой налог» и прикрепляет PDF/изображение к оплате — родитель скачивает его в кабинете.

Чтобы автоматизировать регистрацию дохода, нужно выбрать сервис из списка партнёров ФНС, который предоставляет API для регистрации чеков по внешним платежам, и подключить его в «Мой налог». Тогда сервер после подтверждённой оплаты сможет отправить доход партнёру, получить чек и сохранить его в кабинете. Для этого потребуются договор/доступ к API выбранного сервиса, разрешение в «Мой налог», обработка повторов, ошибок и возвратов. Эта передача пока не подключена. Пароль от ФНС для этого сайту не нужен.

**Уплата самого налога.** В «Мой налог» → «Прочее» → «Платежи» привяжите карту и включите автоплатёж. ФНС рассчитывает налог по зарегистрированным доходам, автоплатёж перечисляет начисленную сумму. Регистрацию доходов он не заменяет.

- https://yookassa.ru/developers/payment-acceptance/receipts/basics — квитанции и чеки, правила для НПД.
- https://npd.nalog.ru/aggregators/ — перечень операторов — партнёров ФНС.
- https://www.nalog.gov.ru/rn91/ifns/ifns6/info/16609940/ — настройка автоплатежа налога.
