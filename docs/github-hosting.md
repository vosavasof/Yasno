# Что можно разместить на GitHub

GitHub хранит исходный код, запускает проверки и публикует статические файлы через Pages. Pages не выполняет Node.js, не хранит общую SQLite-базу приложения и не принимает серверные уведомления об оплатах.

GitHub Actions выполняет ограниченные по времени задания: стандартное задание на предоставленном GitHub runner ограничено шестью часами. Это инструмент сборки и проверки, а не постоянный сервер кабинетов. Codespaces — среда разработки с квотами и автоматической остановкой, а не бесплатный круглосуточный сервер.

У Pages также есть ограничения для сайтов, основная задача которых — коммерческие транзакции или предоставление коммерческого сервиса. Рабочие кабинеты с оплатами лучше размещать на предназначенном для этого хостинге. Публикация демонстрационного интерфейса и хранение кода не превращают Pages в сервер приложения.

Для полной работы «Ясны» нужны постоянное хранилище, защищённый API и обработка уведомлений ЮKassa. Для минимальных расходов можно отдельно оценить бесплатные квоты российского serverless-хостинга; потребуется адаптация хранения и серверного кода, а превышение квот тарифицируется. Доступ из РФ проверяется отдельно от стоимости размещения.

## Конфигурация адреса сервера

В исходниках нет жёстко прописанного домена действующего API. При сборке Pages:

1. Используется `YASNA_API_BASE`, если она задана.
2. При повторной публикации без переменной адрес читается из `config.js` уже опубликованного сайта. Загруженный файл разбирается как данные, его код не выполняется.
3. При первой публикации или недоступности прежней конфигурации нужно задать переменную. Сборка завершится ошибкой вместо отправки данных на выдуманный адрес.

В опубликованном `config.js` и сетевых запросах адрес действующего сервера неизбежно виден браузеру. Удаление его из исходников не меняет размещение сервера и не устраняет сетевые ограничения. Для изменения адреса без потери данных нужно сначала подготовить новое размещение и перенести базу.
